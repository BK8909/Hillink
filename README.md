# HILLINK

**후기 기반 가상 고객 방문·호텔 운영 전략 시뮬레이터**

HILLINK는 호텔·다이닝·여행 후기에서 정리한 고객별 경험과 선택 근거를 활용해, 가상의 방문 조건에서 행동·상품 선택·소비를 살펴보고 운영 전략을 비교하는 서비스입니다.

## 주요 기능

- **고객 라이브러리:** 45개 프로필 열람, 그중 28명 가상 방문 실행
- **고객 흐름:** 당일 방문~3박 4일, 날짜·동행·날씨·행사·객실 조건에 따른 식사·활동·휴식·퇴실 확인
- **행동근거:** 후기에서 확인된 경험, 당시 상황, 비교 후보, 선택 이유 확인
- **전체분석:** 28명 후기에서 확인된 호감·불편 요소와 운영 개선 제안 확인
- **매출 집계·운영 전략:** 실행한 선택을 가상 소비로 집계하고 가격·상품·운영 조건의 A/B 비교

## 설치 및 실행

**필요 환경:** macOS 또는 Linux, Python **3.11**, 웹 브라우저

```bash
git clone https://github.com/BK8909/Hillink.git
cd Hillink/hillink
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
bash tools/start_product.sh
```

실행 후 브라우저에서 **http://127.0.0.1:8994/** 를 엽니다.

다른 포트를 사용하려면:

```bash
HILLINK_PORT=9000 bash tools/start_product.sh
```

서버 실행 없이 설치·자료 상태만 점검하려면 `bash tools/start_product.sh --check`를 사용합니다.

## 이용 순서

1. **라이브러리**에서 고객·프로필·후기 근거를 확인합니다.
2. 방문 날짜·기간·동행·환경·행사·객실 조건을 정하고 실행 방식을 선택합니다.
3. **고객 흐름**에서 방문을 확인하고 **행동근거**에서 선택 이유를 살펴봅니다.
4. **전체분석**, **매출 집계**, **운영 전략**에서 후기 기반 제안과 가상 소비·A/B 결과를 확인합니다.

## 실행 방식과 유의사항

- **규칙 계산:** 별도 API 키 없이 실행할 수 있습니다.
- **저장된 AI 판단 재현:** 저장 당시 정책·입력·설정이 정확히 일치할 때만 원본 응답을 재생합니다.
- **실시간 AI 판단:** 기본 LIVE 판단 정책은 `V19LS`입니다.
- **실시간 AI 판단(개선형):** 선택 시 `INT5M` 정책을 사용하며, 룸서비스 전달 시간을 **미확인**으로 표시하고 식당 후보를 1곳 더 비교합니다.

기본 실행은 **외부 유료 AI 호출을 차단**합니다. 새로운 LIVE 판단은 별도 승인된 API 인증정보, 기존 사용량·비용 원장 및 호출 한도를 설정한 후 `bash tools/start_product.sh --live`로 시작해야 합니다. **공개 저장소만 복제해서 곧바로 LIVE 호출이 가능한 것은 아닙니다.**

11월 8일 개선형의 **비공개 28명 AI 저장 방문 기록은 공개 저장소에 포함되지 않습니다.** 저장 재현과 새 LIVE 호출은 서로 다른 방식이며, 일치하지 않는 기록을 임의로 재생하지 않습니다.

설치·자료 복원·LIVE 환경 설정·검증 명령은 [실행·복원 안내](hillink/handover/RECOVERY.md)를 참고하세요.

> 이 시스템의 고객 행동과 매출은 가상 조건에 따른 시뮬레이션입니다. 실제 고객의 미래 행동이나 호텔 실매출을 예측·인증한 결과가 아닙니다.
