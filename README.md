# HILLINK

**후기 기반 가상 고객 방문·호텔 운영 전략 시뮬레이터**

> “같은 고객이 다른 조건으로 호텔에 온다면 어떤 선택을 할까?”

HILLINK는 고객의 호텔·다이닝·여행 후기에서 경험과 선택 근거를 정리하고, 새로운 방문 조건에서 **행동 흐름·상품 선택·가상 소비·운영 전략**을 함께 확인하는 서비스입니다.

## 최종 제품으로 할 수 있는 일

- **고객 라이브러리:** 45개 프로필을 열람하고, 실행 가능한 28명의 방문을 시뮬레이션합니다.
- **고객 흐름:** 당일 방문부터 3박 4일까지 날짜·동행·날씨·행사·객실 조건에 따라 식사·활동·휴식·퇴실의 연속 행동을 보여줍니다.
- **행동근거:** 고객이 남긴 경험, 당시 상황, 비교한 후보와 최종 선택 이유를 연결해 확인합니다.
- **전체분석:** 28명 후기에서 공통으로 나타난 호감·불편 요소를 모아 운영 개선안을 제시합니다.
- **매출 집계:** 실행한 행동의 상품·수량·가격·혜택을 고객 → 상품 → 업장 → 부문 → 호텔 전체의 가상 소비로 집계합니다.
- **운영 전략·A/B:** 가격·상품·운영 조건의 변경 전후에 고객의 선택과 호텔 전체 가상 소비가 어떻게 달라지는지 비교합니다.

## 운영 개선 결론

후기 분석에서는 **야경·족욕·숲·라운지 등 공간 경험**이 반복적으로 긍정 평가를 받았고, **식음 가격 대비 가치·예약과 대기·조식 시간·일부 시설 이용 조건**에서는 불편이 나타났습니다.

이를 바탕으로 **공간 경험을 중심으로 한 상품 구성**, **부담 없는 식음 선택지**, **시설 이용·예약 편의 개선**을 우선 운영 가설로 제안합니다. 운영 A/B에서는 특정 업장의 소비가 늘더라도 다른 업장에서의 소비 이동이나 할인 비용 때문에 호텔 전체 가상 소비는 늘지 않을 수 있음을 함께 확인할 수 있습니다.

이 내용은 후기와 가상 실행에 기반한 운영 제안이며, 실제 호텔 전체 고객의 통계나 실매출 예측 결과는 아닙니다.

## 사용 방법

1. **라이브러리**에서 고객 또는 유형을 선택해 프로필과 후기 근거를 확인합니다.
2. 방문 날짜·기간·동행·환경·행사·상품 조건을 정하고 **규칙 계산** 또는 사용 가능한 AI 판단 모드로 실행합니다.
3. **고객 흐름**에서 일정을 재생하고, **행동근거**에서 선택 이유를 확인합니다.
4. **전체분석**에서 공통 경험과 운영 제안을 보고, **매출 집계·운영 전략**에서 가상 소비 및 A/B 결과를 확인합니다.

## 설치·실행

Python 3.11과 웹 브라우저가 필요합니다.

```bash
git clone https://github.com/BK8909/Hillink.git
cd Hillink/hillink
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
bash tools/start_product.sh
```

기본 실행 주소: **http://127.0.0.1:8994/**  
포트 변경: `HILLINK_PORT=9000 bash tools/start_product.sh`

기본 실행은 외부 유료 AI 호출 없이 규칙 계산과 일치하는 저장 응답의 재생을 지원합니다. 새로운 실시간 AI 판단은 승인된 인증정보·호출 한도·비용 원장이 설정된 환경에서만 사용할 수 있습니다. **개선형 고객 28명의 비공개 AI 저장 방문 기록은 공개 저장소에 포함되지 않습니다.**

설치 복원, 실행 모드, 검증 방법은 [실행·복원 안내](hillink/handover/RECOVERY.md)를 참고하세요.
