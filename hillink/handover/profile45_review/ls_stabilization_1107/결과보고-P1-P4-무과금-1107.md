## 2. 예외 처리

- 실패를 원인별로 분류해 결정 기록에 남깁니다: 응답 형식 오류·불완전 응답 / 호출 한도(429) / 서버 오류(5xx) / 전송 불확실(시간 초과·연결 끊김) / 비용·호출 상한 / 미승인·키 없음 / 저장 응답 불일치.
- V19LS에서는 **응답 형식 오류·불완전 응답만** 같은 결정에서 한 번 다시 묻습니다(실행된 주문이 없으므로 안전). 429·전송 불확실은 다시 보내지 않고 보류합니다. 결정당 호출은 기존과 같이 최대 2회입니다(검증 거절 재계획 포함).
- 실패를 규칙 계산 결과로 바꾸지 않습니다. 화면에 보류 원인을 구분해 표시합니다.
- 선택 진단은 실행을 막지 않습니다(정상 선택을 낱말 탐지로 차단하지 않기 위해). 결정 기록과 화면에 남깁니다.
- 요청 압축 점검: 보낸 Fact의 id·출처 범위·요약이 원래 근거와 같은지, 모든 기록에 성격 표시가 있는지 결정마다 확인해 기록합니다.
